# Audio Note-Taking Assistant

A full-stack studying tool that helps users generate, save, and manage notes from audio files to boost productivity.

## Features
- Generates notes from audio using OpenAI API
- Users can save, edit, and retrieve notes securely through Firebase
- React frontend for a clean and responsive user interface
- Flask backend for handling API requests and data processing

## Technologies
- React
- Flask
- Firebase
- OpenAI API

## Notes
Designed to assist students and professionals in efficiently converting spoken content into editable, shareable notes.
